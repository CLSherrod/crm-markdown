# Message Templates

Put reusable networking messages in this folder.

This folder is for copy you might send to people, such as email, text, WhatsApp, or DM templates.

Keep this separate from `templates/`, which is reserved for Obsidian note templates such as contacts, companies, communication logs, and monthly reviews.

## Recommended Template Types

Start with a small set:

```text
Warm Check-In.md
Follow-Up After No Reply.md
Meeting Follow-Up.md
Send Resource.md
Ask for Introduction.md
Make an Introduction.md
Thank You.md
Reconnection.md
```

## Suggested Template Format

Use this structure:

```md
# Warm Check-In

## Use When

Use this when you want to stay in touch without pitching anything.

## Subject Lines

- Quick hello
- Thought of you
- Checking in

## Template

Hi {{name}},

I was thinking of you and wanted to say hello.

How have things been with {{specific_topic}}?

Chris

## Notes

Keep this short and personal. Do not send generic check-ins to people who deserve a more thoughtful message.
```

## Rule

Use these as starting points, not scripts.

Before sending, personalize at least one line so the message feels human.
