# Reviews

Monthly relationship reviews go in this folder.

Recommended filename format:

```text
YYYY-MM Monthly Relationship Review.md
```

Example:

```text
2026-06 Monthly Relationship Review.md
```

Create one review per month using QuickAdd:

```text
QuickAdd: People: Monthly Review
```

Keep reviews short. The point is to reset your relationship priorities, not create another productivity report.
